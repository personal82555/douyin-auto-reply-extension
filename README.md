# 抖音评论辅助工具 (Douyin Auto Reply Assistant)

一款 Chrome/Edge 浏览器扩展（Manifest V3），在抖音网页版里搜索热门视频、用 LLM 生成仿真人互动评论、半自动/全自动填入并发送评论。所有 LLM 配置存在本地，可对接任意 OpenAI 兼容接口。

![version](https://img.shields.io/badge/version-1.8.5-fe2c55) ![MV3](https://img.shields.io/badge/Manifest-V3-161823) ![license](https://img.shields.io/badge/license-MIT-green)

## ✨ 功能总览

| 功能 | 说明 |
|---|---|
| 🔥 **今日前10热门** | 侧边栏实时展示抖音热搜 TOP10（官方免登录接口），点击跳转到对应视频列表页，每10分钟自动刷新 |
| 🔍 **关键词搜索** | 输入关键词 → 自动导航到抖音搜索页 → 智能轮询等待渲染完成后抓取视频列表（含时长/日期干扰过滤、4级标题候选池） |
| 📥 **抓取当前页面视频** | 任何抖音列表/搜索页一键提取视频卡片（标题+链接），链接协议自动归一化（`/video/…`、`//www.douyin.com/…` 均正确） |
| 🤖 **LLM 候选文案** | 每条视频生成 3 条候选评论，用户点选一条为主文案 |
| ▶ **单击回复** | 选中文案后一键：新标签打开视频 → 等页面加载 → 自动填入评论框 → 计入统计，用户最后人工点发送 |
| ⚡ **全自动模式** | 抓取当前页列表 → 逐个模拟真人点击视频卡片 → 展开评论区 → 逐字打字 → 点击发送 → 随机间隔 → 回列表续跑；条数/间隔秒数可自定义并记忆 |
| 📺 **过程监视器** | 全自动每一步实时滚动显示（黄=进行、绿=成功、红=失败），像终端一样可视化 |
| 📊 **评论统计** | 总评数 / 月评数 / 周评数 / 日评数 四级统计徽章；评论明细（标题+时间+文案）点击即回跳该视频；可清空 |
| 🌐 **固定侧边栏** | 助手钉在浏览器右侧 Side Panel，切标签不掉数据 |
| 🩹 **自愈连接** | 每次操作前 ping 检测 content script，掉线自动动态重注入，杜绝 "Receiving end does not exist" |
| 🧱 **验证码感知** | 自动识别抖音滑块验证码中间页，明确提示用户手动完成，不瞎点 |
| 🔗 **模型推广位** | 顶部横幅引导注册 ai.88531.cn（一键预填 API 地址，开箱只差一个 Key） |

## 🖱️ 拟人点击细节（全自动）

- 鼠标轨迹：从偏移位置分步滑向目标元素（不是瞬移），坐标带 ±5px 抖动
- PointerEvent + MouseEvent 双通道派发（抖音监听 pointer 级事件）
- 按下→抬起间隔 70~180ms 随机；hover 停顿 80~280ms
- 逐字打字 50~160ms/字符，8% 概率出现 200~500ms "想一想"停顿
- 观看视频 3~6 秒后再操作；发送优先点 `data-e2e=comment-post`，找不到就模拟真人回车发送
- 每步前置验证码检测：弹滑块立即停止并提示手动处理

## ⚙️ 配置（全部本地存储 chrome.storage.local）

- LLM Base URL（默认 `https://ai.88531.cn/v1`，OpenAI 兼容，DeepSeek/Kimi/智谱/Ollama/NewAPI 均可）
- API Key（密文）
- 模型名（默认 `mimo-v2.6-flash`）
- 全自动条数（默认3，上限20）/ 发评间隔秒（默认90，最低15）——保存后跨会话记忆

## 📦 安装

```bash
git clone https://github.com/personal82555/douyin-auto-reply-extension.git
```

1. 打开 `chrome://extensions`（Edge: `edge://extensions`）
2. 开启右上角「开发者模式」
3. 「加载已解压的扩展程序」→ 选择本目录
4. 点工具栏图标 → 「打开助手面板」→ 侧边栏常驻
5. 填 LLM Key → 保存 → 测试连接
6. 浏览器里先正常登录抖音

## 📖 使用流程

1. 搜索关键词 / 抓取当前页 → 列表显示视频标题，每条带「🔗打开」和「文案→」
2. 点某条视频 → LLM 生成 3 条候选 → 点「选这条」→「▶ 用这条回复该视频」自动打开并填入
3. 或直接「⚡开始自动」→ 只评论当前页列表里的前 N 条，全程监视器可视

## 📁 结构

```
├── manifest.json     # MV3 配置（side_panel + scripting）
├── background.js     # SW：LLM代理 / 热榜接口 / 评论历史与统计
├── sidepanel.html/js # 主界面（固定侧边栏）
├── content.js        # 抖音页内：视频抓取 / 填词 / 验证码检测
├── auto.js           # 全自动驱动：真人点击/逐字输入/SPA续跑
├── popup.html/js     # 一键打开侧边栏
└── icons/
```

## ⚠️ 风险提示

- 半自动路径发送永远由用户点击，零封号风险
- 全自动是真实账号的公开行为，新号/低权重账号高频使用会被风控（建议 ≤3条/次、≥90s间隔起步，先半自动养号）
- 插件不逆向任何抖音接口签名，风控策略变化时部分选择器可能需要更新
